Админ-панель отключена

Клиентская админ-панель не может безопасно хранить пароль или управлять заказами на GitHub Pages. Предыдущая версия была отключена, чтобы не создавать ложную защиту и не хранить административные данные в браузере.

Для полноценной админ-панели нужен серверный API с серверной авторизацией, защищёнными сессиями и базой данных.
